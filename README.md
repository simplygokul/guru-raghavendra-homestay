# Sri Guru Raghavendra HomeStay

SEO-first, mobile-first static website for **Sri Guru Raghavendra HomeStay**, Mopidevi.

- Domain: `gururaghavendrahomestay.in`
- Stack: Astro (static generation)
- Primary conversion: WhatsApp / Call / Directions

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content rules

Business facts live in `src/data/`. Do not invent amenities, distances, timings, ratings or reviews.
Pending fields are marked in data files and must not be published as verified claims.
